# Índice del Proyecto - Gestión de Entradas

## Carpetas del Proyecto
* **agentes/** -> Contiene las instrucciones de los agentes y las habilidades.
* **backend-maven/** -> Código en Java para gestionar los datos de clientes y entradas.
* **frontend-angular/** -> Código en Angular para pintar las pantallas con las entradas.

## Agentes Disponibles
1. **agente-backend.md** -> Encargado de la lógica de Java.
2. **agente-frontend.md** -> Encargado de las vistas de Angular.
3. **skill-estilos.md** -> Reglas de diseño (Flexbox y PrimeNG) que usará el frontend.
